# nycosm: OpenStreetMap Features for New York City

OpenStreetMap features for New York City: points of interest, streets,
paths, rail, buildings, land use, parks, water, and transit routes,
clipped to the five boroughs, with full key-value tags. Data are stored
as GeoParquet files and accessed via duckplyr. Map data copyright
OpenStreetMap contributors, available under the Open Database License
(ODbL) 1.0 <https://www.openstreetmap.org/copyright>.
